# Linear Issue Template for SRS Generation

This template can be used in Linear for requesting SRS document generation.

## How to Use in Linear

1. Go to your Linear workspace Settings → Templates
2. Create a new issue template
3. Copy the content below into the template
4. Set appropriate labels (e.g., "srs-generation", "documentation")
5. Assign to the appropriate team

## Labels to Add

When creating the issue in Linear, add these labels:
- `srs-generation`
- `documentation`
- `requirements`
- Priority label (low/medium/high/critical)

## Template Configuration in Linear

### Recommended Settings:
- **Template Name:** SRS Generation Request
- **Description:** Request generation of a Software Requirements Specification document
- **Default Project:** [Your project name]
- **Default Labels:** srs-generation, documentation
- **Default Assignee:** [Project manager or tech lead]
